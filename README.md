## 程式用途

本程式整理「桌遊體驗」與「電影欣賞」兩場活動的報名名單。原始名單是以逗號分隔的文字，含有多餘空白、大小寫不一致與重複報名。

程式的處理步驟：

1. 移除半形空白、轉成小寫，再用 `split(",")` 拆成保留重複的 `list`。
2. 把兩份 list 各自轉成 `set` 去除重複。
3. 用交集、聯集和兩個方向的差集比較兩場的參加者。
4. 用 `sorted()` 排序名單，並用切片 `[:2]` 取得通知名單前兩位。
5. 用 `dict` 保存摘要，計算人數、人次與應收費用（桌遊每人 120 元、電影每人 80 元），最後用 f-string 輸出。

各種資料型別在本題的用途：

| 型別 | 保存的資料 |
| --- | --- |
| `tuple` | 固定的兩個活動名稱 `activity_names` |
| `str` | 原始報名文字 `board_raw`、`movie_raw` |
| `list` | 整理後保留重複的名單，以及排序後的顯示名單 |
| `set` | 去重後的名單，用來做交集、聯集、差集 |
| `dict` | `unit_fees` 查詢每人費用；`summary` 保存人數與金額摘要 |

## 個人回答

### 問題一

測試一的桌遊串列是 `['amy', 'ben', 'amy', 'cora']`，雖然有 4 筆資料，但 amy 報名了兩次。依照規則，同一人在同一場只算一位、只收一次費用，所以實際只有 amy、ben、cora 三個人，費用是 3 × 120 = 360 元。如果用串列長度 4 來算，就會多收 120 元。

直接拆成 list 時，保留了**原本的順序和重複的資料**，可以看出誰重複報名、報名的先後順序；但 list 不會自動去重，不能直接拿來算人數。轉成 set 之後，**重複的資料被去除**，可以正確計算人數，也能做交集、聯集等比較；但 set 會**失去順序和重複次數**，也不能用索引取值，所以要顯示時得先用 `sorted()` 排序。

### 問題二

測試三中，桌遊集合是 {amy, ben, cora}，電影集合也是 {amy, ben, cora}，兩個集合完全相同。所以：

- 交集 = 聯集 = {amy, ben, cora}，總不重複人數是 3 人。
- 兩個方向的差集都是空集合 `[]`，沒有人只參加其中一場。

「報名人次」是兩場各自去重後的人數相加：3 + 3 = 6 人次。每個人都參加兩場，所以每人算兩人次。

費用也是每場分開計算：桌遊 3 × 120 = 360 元，電影 3 × 80 = 240 元，合計 360 + 240 = 600 元。總應收看的是各場人數，而不是總不重複人數，所以雖然只有 3 個不同的人，仍然是 600 元，和測試一相同。
